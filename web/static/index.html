pegRNA-BLAST · prime-editing C-terminal knock-in designer

Designs pegRNAs for C-terminal tagging (recoded TJ-PE, neurogenomics/prime-editing). You supply the target (genome window + insert site) and the cargo; the pipeline designs the guides — PRIDICT2 designs the pegRNA spacer (and the ngRNA, PBS and RTT) on CPU, then a gate cascade (off-target · cryptic-splice · splice · structural importance · 2D structure · docking) filters the candidates. Fill in the template and cargo and click Design pegRNA — you do not type the guide (a spacer override lives under Advanced overrides for the rare case you need one). fake = design logic with stand-in scorers (and a fake PRIDICT runner); api = real gates (CPU + hosted-model APIs; docking via NVIDIA Boltz-2).
